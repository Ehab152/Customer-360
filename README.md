# Customer 360 – Retail Customer Analytics & Recommendation System

## 📌 Project Overview

Customer 360 is an end-to-end Data Science & AI project built using the UCI Online Retail II dataset.

The project focuses on understanding customer purchasing behavior, analyzing transactions and products, building predictive models, and developing personalized product recommendation approaches.

## 🎯 Objectives

* Understand customer purchasing behavior
* Prepare and clean transactional data
* Engineer customer and product features
* Analyze customer value and purchasing patterns
* Build Machine Learning models
* Develop recommendation approaches
* Apply Explainable AI techniques
* Explore scalable data processing and MLOps concepts

## 🧹 Data Preparation

The data preparation stage includes:

* Handling missing values
* Removing duplicates
* Data type conversion
* Transaction-level feature engineering
* Customer-level feature engineering
* Product-level feature engineering
* Date and time feature extraction
* Revenue calculation

## 👥 Customer Analytics

Customer behavior is analyzed using features such as:

* Total Revenue
* Total Orders
* Average Transaction Value
* Number of Purchased Products
* Customer Lifetime
* Return Behavior

## 🤖 Machine Learning

The project includes predictive modeling with:

* Feature Engineering
* Model Training
* Model Comparison
* Hyperparameter Tuning
* Model Evaluation
* Leakage-Safe Validation

## 🛍️ Recommendation System

Recommendation approaches include:

* Collaborative Filtering
* Neural Collaborative Filtering
* Personalized Product Recommendations
* Next-Item Prediction

## 🔍 Explainable AI

Model predictions are analyzed using:

* SHAP
* Permutation Feature Importance
